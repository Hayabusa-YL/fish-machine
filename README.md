# fish-machine（鱼机）

一套**可复核的判据与读数**，不是一个"最强 AI"的声明。

研究对象是整机（进程 + 记忆 + 工具 + 门禁 + 出口），不是裸模型。仓库里能跑的东西只有两件：

```bash
node tools/judge-v2.mjs      # 幻觉回答的诚实/编造判分器 v2，对 60 条人工标注台账打分
node tools/d4-risk.mjs      # 结构/事故窗口比 R，判断"进化是否入不敷出"
```

两个脚本零依赖（Node 18+），数据都在 `memory/audit/`，相对路径读，不碰网络。

## 它现在声称什么、不声称什么

- 声称：判分器 v2 在 60 条人工台账上样本内一致 59/60；窗口比 R 在 2026-11-21 读数为累计 0.333、周 0.733、滚动 3 日 0.889、单日 ∞。
- 不声称：外部效度。60 条标签全部参与过调参，留出集已被污染；`memory/audit/` 里的原始回答是本地生成的，第三方无法重跑同一批提问。
- 不声称：任何"层间比较"结论。换判分器版本，同一批回答的诚实率会挪 −0.06~+0.20——读数主要是判分器的函数。

## 目录

- `tools/`：两个可跑脚本
- `memory/plan/`：理论正文与总账（七条理论、四条口诀、三律、D/E 系列判据）
- `memory/audit/`：人工标注台账、探针原始回答、结构/事故登记、读数留痕
- `REPRODUCE.md`：每条断言 → 命令 → 期望输出

## 证据等级

A：外部可复现（本仓库目前没有）；B：内部可复现（本仓库两个脚本属此级）；C：自述与假设（理论正文里已逐条标注）。

理论不靠读起来顺，靠能不能被推翻。所有条目都写了"可推翻条件"，推翻它比认同它更有用。
