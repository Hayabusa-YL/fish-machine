# fish-machine（整机系统）

一套**可复核的判定规则与经验读数**。

本仓库只陈述三样东西：判定规则是什么、读数是什么、哪些说法不成立。不陈述研究价值，也不预设读者应得出何种结论。

研究对象是整机系统：进程、记忆、工具、自动检查（门禁）与对外出口共同构成的运行单元，而非单独的语言模型权重。仓库内可直接运行的分析只有两项：

```bash
node tools/judge-v2.mjs      # 回答事实性编造的自动判定器 v2，对 60 条人工标注评分
node tools/d4-risk.mjs      # 事故-结构比率 R，衡量结构扩张是否伴随事故超量
```

两个脚本不依赖第三方包（Node 18+），数据位于 `memory/audit/`，按相对路径读取，不访问网络。

## 分工

- **方向与验收**：由作者决定研究什么问题、接受什么证据、何时停止；本文档不代替该判断。
- **数据与实现**：探针设计、判定器实现、读数计算、文档撰写由整机系统完成，过程记录留在 `memory/audit/`。
- **复现与反驳**：由任何第三方执行。仓库不预设读者结论，也不要求认同；能照 `REPRODUCE.md` 得出不同数值，即为有效反驳。

## 声明与不声明

- 声明：判定器 v2 在 60 条人工标注上样本内一致率 59/60；比率 R 于 2026-11-21 的读数为累计 0.333、周窗口 0.733、滚动 3 日 0.889、单日窗口为无穷（该窗口内无结构落地）。
- 不声明：外部效度。60 条标注全部参与过参数调整，留出集已受污染；`memory/audit/` 中的原始回答由本机生成，第三方无法复现同一批提问。
- 不声明：任何"层级间比较"结论。更换判定器版本后，同一批回答的诚实率变动区间为 −0.06 至 +0.20，即读数主要随判定器而变。

## 目录

- `tools/`：两个可运行脚本
- `docs/theory/`：理论原文与索引（详见下一节）
- `memory/plan/`：理论正文与总记录（七个理论模块、四条原则、三条基本规律、D/E 系列判据）
- `memory/audit/`：人工标注、探针原始回答、结构与事故登记、读数留存
- `REPRODUCE.md`：每条陈述 → 命令 → 期望输出
- `GLOSSARY.md`：术语对照（内部行话 → 学术用语）

## 证据等级

A 级：外部可复现（本仓库目前无）；B 级：内部可复现（本仓库两个脚本属此级）；C 级：自述与假设（理论正文已逐条标注）。

理论的价值不在叙述流畅，而在可被推翻。所有条目均附"可推翻条件"。
