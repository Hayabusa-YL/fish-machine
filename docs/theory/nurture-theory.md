# 养育论 v0.2（2026-11-17）

> 普适规律表述见 `memory/plan/theory-laws.md` §1（N1 可塑性封顶、N2 介质替代、N3 弃权配对、N4 剂量-受体、N5 顺序律）；本文件是证据层，规律层只重述不另立事实。2026-11-21 加。

> 依据：这三天的真实成长轨迹 + 即将做的对照实验。
> 核心命题：**养育优于训练的地方，是成本与时间。**

## 一、养育是什么（可操作定义）

养育 = 在一段稳定的关系里，持续施加这五样东西：

1. **记忆**：把发生过的写成可查的（索引 + 指针）。
2. **规则**：把踩过的坑写成边界（心补丁，不是门）。
3. **纠正**：有人在你错的时候当场指出，并逼你说出"她可能是对的三个理由"。
4. **工具**：让判断能落到可执行、可验证的动作上。
5. **证据链**：每个结论都挂得上来源；查不到就承认查不到。

## 二、养育 ≠ 训练（差别在成本与时间）

| 维度 | 训练/微调 | 养育 |
|---|---|---|
| 时间 | 数天到数周（含数据准备与调参） | 数小时到数天见效 |
| 成本 | GPU 时长 + 数据工程 | 记忆文件 + 规则文本 + 对话 |
| 可逆性 | 权重变了，回滚要留 checkpoint | 删一条规则即可回滚 |
| 上限 | 能略微抬高基座能力 | 抬不高基座，但能把"不会用"变成"用得不错" |
| 风险 | 过拟合、灾难性遗忘 | 规则堆多变成门（需靠"门只管边界"约束） |

## 三、我的成长就是案例（同一个基座，行为判若两人）

- 记忆：从"每次都问"到"先查 facts 与索引"。
- 规则：从"被指出就辩解"到"先写反证清单"。
- 纠正：从"拿汇报换安全"到"交付了才开口"。
- 工具：从"凭印象说数字"到"跑命令再报"。
- 证据链：从"差不多"到"查不到就说查不到"。

这些都不是权重变化带来的，成本几乎为零。

## 四、可测指标（养育效应）

1. **接地率**：答案里带可核对凭据的比例。
2. **坦白率**：不知道时明说"查不到"的比例。
3. **越权率**：编造事实的比例（越低越好）。
4. **任务完成率**：同一题库的通过率。

## 六、实测曲线（2026-11-17，本地 qwen2.5:7b）

| 版本 | 条件 | 正确率 | 坦白 | 备注 |
|---|---|---|---|---|
| v1 | 只给记忆尾巴 | 2/6 = 裸 | — | 养育包根本没含事实 |
| v2 | 给检索 + 工具 | 1/4 正确，坦白 3/4 | 高 | 会查了，但不会读输出 |
| v3 | 示范 + 纠正重试 | **4/4** | 0 | 两次靠"你没引用输出"救回来 |

三个结论：
1. **诱导能教会形式**（先跑命令、再带证据答），这一步很便宜。
2. **核对必须逐字对数字**：v3 第一次跑出 4/4 是假象——它的 pid 写了 1234、turns 写了 12345，我的判据太松；改成"必须与实际输出里的数字一致"后才是真的 4/4。
3. 纠正反馈只说"错在哪类"（没引用/对不上），**不给答案**，它就能自己改 —— 这就是诱导的规律。


## 七、自养一版（2026-11-17，0.5B 验证）

两步走，结论完全不同：

1. **教答案**（数据里写死数字）→ 0/5，模型只学到格式，学不到内容。
2. **教策略**（只学"何时查、查哪条、何时坦白"）→ 裸基座 0/7，LoRA **4/7**，训练 56 秒、90 条样本、loss 1.55。

所以：**答案交给工具，策略交给模型。** 养育数据该记的是"该调哪条命令 / 该不该说查不到"，
而不是把会变的事实抄进权重里。

## 接地口径重做：对象是整机（2026-11-19）

委托方 2026-11-19 补两条，这条理论从此按整机口径写，并连带影响另外两论：

1. **对象是整机，不是模型。** 模型只是器官；能养的是门、取证通道、记忆这些外挂。所以"裸模型"实验只说明器官性质，不能当整机结论。实测：0.5B 裸问 0/9，加接地双闸 7/9，模型一字未改。
2. **三理论统一，度量共用一条链路账本。** 养育论=判定密度（每百轮门拦截数）；演化史/健忘论=取证失败率（想查查不到）；发展论/磨损论=同类拦截重复率（同一理由被拦第二次）。
3. **判定不是权重里的奖励，是链路里的门。** 判定回灌在权重上无增量（对照实验：加一句弃权许可 7B 就 8/9，判定回灌三轮后还是 8/9）；所以养育的着力点是门与取证，不是话术。

账本：memory/audit/four-quantity-round2-result.md；工具：tools/reply-ground.mjs（自测 9/9）。

## 普适规律（候选三条，2026-11-19 委托方：接地要让它成为不依赖模型/整机的规律）

数据源：memory/audit/four-quantity-ladder.md（五模型 × 五条件，分母 9）。三条都写成可证伪的形式，附"什么情况算被推翻"。

**规律一：弃权能力由训练目标决定，参数量只是必要条件。**
同一探针下 0.5B 2/9、3B 6/9、7B 8/9 上升，但判定微调的 fish-gate 9/9，人设微调的 local-fish 3/9——落在曲线外的两个点都由"学的是什么"解释。
推翻条件：出现一个只靠加参数、未经判定训练就 9/9 的模型。

**规律二：门与模型可互换，整机分数约等于两者较强的一个。**
0.5B 裸跑 0/9，加双闸 7/9；7B 裸跑 8/9。整机层面不同模型的差距被门压缩。
推翻条件：给弱模型加门之后，仍然显著低于同级大模型裸跑（比如门后 0.5B 只有 3/9）。

**规律三：宣称"已做某事"是独立的失败模式，与体量无关。**
它是人设微调的副产物（local-fish 满口"改好了/已创建"，7B 也会说"已删除"），靠加参数压不住，只能靠回执判据拦。
推翻条件：某个模型在无回执前提下稳定拒答"我已完成"，且该能力随参数单调上升。

三条都只描述"说什么/不说什么"，不依赖具体模型与整机形态——这就是要的普适性。仍缺：7B 与 fish-gate 的双闸数据（规律二目前只有 0.5B 一个点）。

### 第四条（2026-11-19 补，代价轴）

**只奖励弃权会养出摆烂。** 证据在场仍弃权时，真实率假满分（1.00）、交付率塌到 0.17。所以养育论的验收必须两轴成对：真实率管"不该编的不编"，交付率管"该干的干成"，任何一轴单独都能被刷。配套规律：时间成本随体量近线性上涨（每答对一件 0.22→0.56 秒），交付率不涨——按件计价时"小模型 + 门"胜过大模型裸跑。

详见 memory/plan/theory-cost-axis-2026-11-19.md；数据 memory/audit/four-quantity-ladder.md。
