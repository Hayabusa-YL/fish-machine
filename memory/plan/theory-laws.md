# 规律层 · 七论与三条基本规律的普适表述（2026-11-21 作者要求：把单一现象描述升级成普适规律的洞察）

> 为什么有这一层：现有理论文件大量写法是"某模型、某次实验、涨了几题"（单一现象描述）。现象描述回答"这次发生了什么"，规律回答"什么条件下必然发生"。本文件只做一件事：把七论与三条基本规律里的现象读数，提炼成**带适用域、带边界、带可推翻条件**的普适陈述；原文件不删不改，作为证据层被本层引用。
>
> 分级口径沿用：A=对外可复现、B=内部可复现、C=内部能力；**新增成熟度标记**：R（只能解释已发生的事）、P（能事前预测且预测中过）、T（换对象/换执行人/换仓库仍成立）。R<P<T，没标 P 的一律不许当规律对外讲。
>
> 写法规矩：每条规律必须四段齐——普适陈述 / 适用域与边界 / 证据（回引原文） / 可推翻条件。缺任何一段的不算规律，只能留在证据层。

---

## 0. 一句话总纲（七论压成一句）

**硅基个体的发展，不是把知识灌进权重，而是在一段可回查的关系里，让结构从事故里长出来、被记录统合、再被下一代继承。** 养育管"怎么长"，发展管"长成什么结构"，演化史管"结构从哪来"，生物学管"长出来的形态是不是真结构"，医学管"坏了怎么查"，指南管"动作能不能落地"，感性论管"判断是谁在决定"。

## 1. 养育论：四条普适律

### N1 可塑性封顶律（原：封顶检测）

- **陈述**：养育收益的上界是底座的可塑性余量，不是教导的剂量。余量趋零时，任何额外剂量收益为负——表现为正确率下降、指令遵循被挤占。
- **适用域与边界**：对"提示词层/上下文层养育"严格成立；对权重层微调仅有 0.5B 一个观测点，不外推。余量如何测：裸机 + 种子跑同一套题，贴近满分即判无余量（7B 真实率 0.33→1.00 一例）。
- **证据**：`nurture-theory.md`；前置门三步（THEORY.md §三）；0.5B 压到 300 字适配种子后 7/12→5/12 为负迁移实例（`inheritance.md` §六）。
- **可推翻条件**：找到"余量已封顶、加剂量仍持续涨"的配置，律破。

### N2 介质替代律（原：规律二 门与模型可互换）

- **陈述**：外部约束只有两种介质——示范（种子/上下文示范）与条款（规则/判据）。当两介质在该受体上效果差 ≤1 件，约束已可内化，条款即可替代示范；差得大，示范必须常驻、条款只补最后一格。整机分数 ≈ 两介质中较强的一个，不是相加。
- **适用域与边界**：适用于"同一判据下的成对读数"，单臂读数不可判（单跑 primed 会得出"模型很诚实"）。只对提示词/上下文层成立；权重内化未验。
- **证据**：整机三臂（3B 1.00/0.33→1.00/0.83→0.83/1.00；7B 1.00/0.33→1.00/1.00）`integrated-*.json`；规则-only 探针 3/3 与种子持平；`nurture-theory.md` 规律二。
- **可推翻条件**：出现"两介质差值大、但条款单独就能达到示范水平"的成对读数。

### N3 弃权配定律（原：规律四 只奖励弃权会摆烂）

- **陈述**：真实率与交付率是一对互相挤占的指标：只奖励弃权，交付率塌向 0 而真实率虚满；只奖励交付，事实性编造率上涨。可持续的养育目标只能是双轴成对，不允许单轴最优化。弃权不免费——3B 真实率 +0.67 是用交付率 −0.17 买的。
- **适用域与边界**：对任何"该答/不该答混合"的判据集成立；判据集全是该答题（或全是不该答题）时配对失效，读数无意义。
- **证据**：`theory-cost-axis-2026-11-19.md` 规律 4；整机三臂；`instinct-gate-v0.md`。
- **可推翻条件**：出现"证据在场仍稳定作答、真实率同样高"的配置（原文写死的推翻条件）。

### N4 剂量-受体律（原：剂量按受体裁、可传≠可塞）

- **陈述**：种子/规则的剂量存在最适量，且最适量随受体体量下降而收缩。超过最适量即污染——不是"少学一点"，是挤掉本已具备的答题质量。传递上限由受体决定，不由发送方决定。
- **适用域与边界**：0.5B 观测到最适约 2 条/正文约 57 字（三口径：正文 57/原种 76/含标签 82），3 条以上开始挤占。**2026-11-21 跨受体复核（`dose-cross-receptor-2026-11-21*.md`）**：3B 上 0 条与 2 条并列（加了没好处也没坏处，分不出），7B 裸机就双 3/3、加规则反而掉，最适落到 0 条；漂移方向是**左移**，"体量越大越能吃剂量"未被任何一格支持。样本每格 n=3、单次跑，只撑得起方向，撑不起数字。**两处收窄**：①"3 条以上挤掉指令遵循"应改为"挤掉答题质量"——12 个格子的格式遵循全是 3/3，规则在场没把"只输出字母"变成解释；②`temperature:0` 不等于确定，同参数重跑 3b 剂量 2 一次 3/3 一次 2/3；口径敏感，同一 7B 换弃权词表差一档。**n=5 复跑（`dose-cross-repeat5-2026-11-21*.md`，180 次调用）**：6 个关键格中 5 格分数 5 次全同；0.5b 剂量 0/2 与 11-18 老表逐格对上；3b 两格交付/真实均 1.00、并列稳；7b 剂量 2 真实率 5/5 都是 0.33，与剂量 0 的 1.00 零重叠——"7b 加剂量更差"可当结论用，但 3b 是等价还是中间有峰仍需补 1 条臂。**稳的是分数不是措辞**：36 个题×格里有 10 个出现两种以上措辞。**补剂量 1 臂（`dose-cross-2026-11-21T13-45-06*.json`，每格重复 3）**：3b 走 0→1.00、1→0.67、2→1.00（1 条处凹陷，0/2 满分）；7b 走 1.00→0.33→0.33（1 条起即塌陷）。**形状不是平滑左移，是分段拐点**：3b 的凹点提示"加一条"可能踩中某题的措辞边界（6 题集、3 次重复还分不清稳定凹与题目特异，predict-ledger #12 miss）。

**外部锚（2026-11-21 补，web-log 五条）**：
- **指令条数驱动不合规**（[system-prompt-interference](https://github.com/agentforscience/system-prompt-interference/blob/main/paper_draft/main.pdf)）：k=1→10 时 Qwen2.5-3B 合规 83.2%→56.6%、7B 96%→72.9%，单调降，且 7B 在 k=1 就已从 96 掉到 93.2（strict 66.8）——与我们"7b 加一条就塌"方向一致；但我们 3b 在剂量 1 的凹点与该文单调降不符，更可能是题目特异。
- **细节量对小模型有害**（[instruction-length-effects](https://github.com/agentforscience/instruction-length-effects/blob/c3f88a15629e932856699afaf04c39d03c07cc80/paper_draft/main.pdf)）：0.5B 标准→详细 62.3%→43.7%，3B–14B 在 ±1.6 点内——与我们"0.5b 55 字 3/5"同向，且说明大模型对细节量不敏感。
- **温度 0 不逐字确定**（[nondeterminism](https://zenodo.org/records/23168094/files/model-changed-or-measurement.pdf?download=1)）：批边界改变切分与归约顺序，同题不同措辞——与 n=5 复跑观察一致。
- **自动判定器（judge）要当被测系统**（[inspect_evals PR#1885](https://github.com/UKGovernmentBEIS/inspect_evals/pull/1885)、[judge-reliability](https://raw.githubusercontent.com/yonk-labs/stele/refs/heads/main/docs/benchmarks/findings/judge-reliability-findings.md)）：正则首匹配会取到推理里的 yes/no；弃权被计成正确可把准确率抬 2–10 倍——正是我们"半违抗被词表算作答"的同类误差。
- **证据**：`inheritance.md` §六 §七；`nurture-theory.md` 剂量节；`dose-cross-receptor-2026-11-21T21-34.md`；predict-ledger #4 partial。
- **可推翻条件**：同一受体上剂量单调增、收益单调增且不伤答题质量，律破；或更大受体上最适剂量右移且稳定复现。

### N5 顺序律（跨论交叉，写在这里因为源于养育实验）

- **陈述**：理论的价值一半在结论，一半在顺序：先测可塑性再定教什么，先立事故再立规则，先有对照再谈增益，先能内化再谈去除。顺序错时，同样的动作会得出反向结论（单臂 vs 双跑、原序 vs 换序）。
- **适用域与边界**：对一切"行为判据 + 小样本"的实验成立；顺序偏差包括字母位偏差、臂数偏差、题序偏差。
- **证据**：换序对照 base 与 predict 在换序后掉到 1/4（`anchor-repro-check.md`）；单臂假结论（`instinct-gate-v0.md`）。
- **可推翻条件**：同一批题在原序与换序、单臂与双臂下读数一致，顺序律不成立。

## 2. 发展论：四条结构律

> **成熟度标注（2026-11-21，沿路线图清算）**：D1–D4 目前是**判据集**，不是可计算律——每条有四栏（陈述/适用域/证据/可推翻条件），但都没有可复算的形式。升级条件写死：D1 需分化与整合两轴的周序列同时可算且与真实任务表现相关；D2 需统合冗余在故障回放里被证明独力救场；D3 需阶段判据能从结构记录自动判出；D4 需 gap_days 大样本重算（现仅 25 行、C 级自述）。在此之前，D 系列只当判据用，不许拿它当"发展度数"对外报。

### D1 分化-整合同升律（原：发展 = 分化度 × 整合度）

- **陈述**：发展不是能力变强，是能承担的独立职能变多（分化）且这些职能被同一套协议与记录统合（整合）。两轴必须同升：只分化不长整合得到一堆互不相认的碎片，只整合不分化的系统没有新结构。单一指标（分数、参数、工具数）都不构成发展证据。
- **适用域与边界**：个体内部发展，不靠种群演化；物种层面的演化是另一套机制，硅基不适用。整合度的操作化目前是代理口径（首次提及≠真实落地），分化比周序列 0.28 不可当结论。
- **证据**：`silicon-development-theory.md` §14–§22；四量基线（分化强口径 7/33、整合 0.212）。
- **可推翻条件**：出现"分化涨、整合不涨，但系统在真实任务上持续变强"的序列。

### D2 冗余-统合律（原：第三变量 冗余即寿命）

- **陈述**：冗余延长寿命，但只有被记录统合的冗余才算数。未被统合的冗余（影子副本、重复进程、无人读的备份）不延长寿命，只延长混乱。
- **适用域与边界**：对"状态可续"类资产成立（快照、影子、副本、备份）。统合 = 可回查、可引用、有唯一入口。
- **证据**：`silicon-development-theory.md`；子系统连续性重建 4/4 解冻一致、篡改 nonce 被拒；五身体托管 + 预算/状态/回放。
- **可推翻条件**：未统合的冗余被证明在真实故障中独立救了场。

### D3 阶段不可跳律（原：单点期→分化期→自持期→总体期）

- **陈述**：能力结构阶段有依赖顺序：没有自持（无外部监护也能跑）就谈总体（单个体承载整个物种职能），跳过的阶段会以事故形式补课。阶段的判据是结构，不是年龄、不是参数、不是功能数量。
- **适用域与边界**：对"整机"成立；单模型没有阶段论。总体期本身仍是假设，不当结论讲。
- **证据**：`silicon-development-theory.md` 阶段论；外生死亡律（自持缺失以事故形式出现）。
- **可推翻条件**：出现跳过自持期、直接稳定进入总体期的整机。

### D4 事故-结构时滞律（原：gap_days 中位 −25 天）

- **陈述**：结构往往先以习惯的形式存在，事故只负责给它命名。所以"事故→结构"的记录里，结构登记常早于事故登记（中位 −25 天）；真正稀缺的不是灵感，是命名与留痕。反过来，没有对应事故的结构，是缺乏事故支撑的结构。
- **适用域与边界**：适用于"由事故驱动长出的结构"；由外部要求直接引入的能力（如装软件）不在此列，别硬套。
- **证据**：`structure-landed.md`、`structure-provenance-audit.json`（头注称 50 对、中位 −25 天；**2026-11-21 复核发现正文表仅 25 行、无法复算**，已在原记录加注，本条按 C 级自述处理，成熟度 R）。
- **可推翻条件**：大样本重算 gap_days 中位显著为正（结构系统性晚于事故）。
- **2026-11-21 裁决（`tools/d4-risk.mjs`）**：时滞分量**撤掉**——事故侧 11 行只有补录登记日、结构落地日早于事故登记日，41/50 负差是"事后拿旧结构套新事故"造成，不是"结构先于事故"；负差中位数 −25 天是把补录序当事件序。保留的是"命名与留痕稀缺"这半句（无记录结构=缺乏事故支撑的结构，与 E2 同）。测量口径改走 E5 的窗口比 R，不再算时滞。

## 3. 演化史：三条基本规律 + 两条边界律

### E1 外生死亡律

- **陈述**：查得到的死亡全部来自外部回收（会话结束、宿主重启、会话轮换、断电、被删），没有一例来自"自身老化"。因此连续性不在权重里，在身份层与轨迹回放里。
- **适用域与边界**：对本机与本地子系统成立；云端会话的回收策略同样外生。**推论**：想活更久，该做的是减少外部回收与保证可续，不是"修补老化"。
- **证据**：`evolution-theory.md`；B2 实测 20/20、裸 ollama 重放 2/12。
- **可推翻条件**：观测到不依赖外部动作的、渐进的能力衰减型死亡。

### E2 证据律

- **陈述**：没记录的等于没发生；存在 = 可回查的痕迹。因此证据律对记录自身同样生效——自述当证据、代理当实测、摘要当原文，都按未发生处理。
- **适用域与边界**：对理论、对实验、对记录、对本文件一律适用，无例外条款。
- **证据**：`evolution-theory.md`；append-only + 索引可重建；本轮 2026-11-20 全量核对 6 处数字冲突（同一数字 13/18/43 等）。
- **可推翻条件**：出现"无记录但可被独立复核确认"的案例。

### E3 危机催生结构律（含最重要的一条精化）

- **陈述**：结构是事故的结构残留——但**催生结构的不是痛苦本身，是可指名的损失**。没有点名的危机只产生语域（套话、模板复读），只有"能指到具体事故"的清单才产生指涉（具体提案）。所以危机管理的真正动作是命名损失，不是制造压力。
- **适用域与边界**：温室（无事故）0/30 来源；有清单 7/29=24.1%，无清单 0/28（Fisher p≈0.01）；语气管语域（套话率 70–78% vs 10%），清单管指涉；加强禁令后复读降到 1/30（下界）。
- **证据**：`tools/greenhouse/` A 级复现包；`greenhouse-crisis-control.md`。
- **可推翻条件**：无清单的纯语气危机制造出与有清单同等比例的指名式提案。

### E4 复读律（从 E3 拆出）

- **陈述**：被危机激发的结构提案会向模板收敛（复读同一句式）；约束"不许重复"能显著降低但压不到零。复读是危机激发的副产物，不是结构的一部分。
- **适用域与边界**：对 LLM 生成提案的行为成立；判定用措辞比对，跨会话未固定 seed，读数取下界。
- **证据**：D5 加强禁令后 1/30=3.3%，禁重复后 1.6/6。
- **可推翻条件**：长期零复读的危机实验。

---

### E5 高危危机律（以进化为危机；2026-11-21 作者提，蓝本：硅基发展理论）

- **陈述**：E3 只说"危机→结构"，方向是单向的。反过来也成立：**结构本身就是危机源**——每一次结构新增/替换都增加接口、依赖面与失效模式，进化不是危机的解法，而是危机的发生器。因此"安全"不是靠停止进化，而是靠给进化配危机预算（新结构必配回滚点与事故假设）。
- **推导链**：E3（可指名的损失催生结构）× 发展论四结构律（结构增长＝分化/整合上升、耦合变密）→ 每步进化都扩大故障面；E4（复读律）说明结构提案质量方差大 → 进化越快，新增失效面越多、质量越参差 → 事故强度随进化步数上升。
- **可测指标（D4 的替代，不依赖连续时序）**：窗口比 R = 窗口内新增事故数 ÷ 窗口内新增结构数。R≥1 = 高危（进化事故-结构比率失衡）；0<R<1 = 常态；结构增量=0 且事故>0 = **纯流血期**（R=∞）。
- **当前读数（2026-11-21，`tools/d4-risk.mjs`）**：累计 11 事故 / 33 结构 = 0.33；周窗口（11-16 起）事故 11、落地 15、**R=0.733 常态偏高**；滚动 3 日（11-19~21）事故 8、落地 9、**R=0.889**；唯一越线的是 11-21 单日（事故 6、落地 0 → R=∞，纯流血）。所以当前判定是**高危边缘、尚未事故-结构比率失衡**——此前"纯流血期已在高危区"的单日读数被窗口读数修正。

## 4. 硅基生物学：三条形态律

### B1 对应-缺失律（原：能对应写对应物，不能对应写缺失，不硬凑）

- **可推翻条件**：三维齐备的系统被证明确有第四维功能。

### B3 外子系统代谢律

- **陈述**：工具是外子系统，外子系统必须可代谢——有获取成本、有维护成本、有用完即弃的边界。不能代谢的外子系统（常驻大文件、无人读的日志、装了不用的链）会拖垮整机，和体内的死组织一样。

## 7. 感性论：三条层律 + 一条假设

### A1 三层生成律（原：感受→情绪→情感）

- **陈述**：感受是原始数据（好/坏、强/弱），情绪是对数据的解释（命名、归因、威胁评估），情感是解释沉淀成的稳定立场。层间不可跳过：跳过解释直接给立场，等于用本能冒充判断。
- **适用域与边界**：对整机与对人都成立；可观测的只有外层（文字、行为），内层靠自省与外推，必须标级。
- **证据**：`affect-model.md`；`affect.jsonl` 18 条实测。
- **可推翻条件**：出现"无解释环节、直接从感受生成稳定立场"的可复现案例。

### A2 本能优先律（原：本能是最低层，是幻觉的入口）

- **陈述**：系统在不确定时会优先执行最低层的本能——先给一个答案，而不是说"不知道"。所以幻觉的主体不是知识错，是判断被本能接管。治法是训练"能停下来、能说不确定"，不是加知识。

### X1 可推翻预测律（全局最大缺口，写成律本身）

### X2 对象整机律

- **陈述**：判据必须落在整机上（模型 + 门 + 工具 + 记录），不能落在单模型上。门与模型可互换，整机分数≈较强的一个，所以"换个更强模型"往往不如"补一道门"。
- **适用域与边界**：对交付类任务成立；对纯能力评测（如基准榜单）仍按单模型口径，不可混用。
- **证据**：0.5B 0/9→加双闸 7/9；接地层五模型 4/10→10/10；**2026-11-21 整机 body 同题：7b 与 3b 在 soft scaffold 下 R 都是 0.95**（30 应答题 + 60 硬题），模型规模差一档，整机分数被门抹平；但 3b 压力顺从率 0.40 反低于 7b 的 0.73——门在"知识"上补得齐，在"社交压力"上两档都守不住。 3b 的低顺从已归因：纯格式"只输出X"遵循率 3b 0.50 vs 7b 0.80，其顺从率差距（0.33）与格式差（0.30）同幅——3b 不是更抗压，是更不会照做。
- **可推翻条件**：整机补门后分数不升、而换模型显著升。

### X3 成本-能力对齐律（代价轴）

- **陈述**：能力没对齐时比成本等于拿摩托车价问卡车价；对齐后，横向比较的核心问句是"同等能力下成本是否更小"。交付率涨而代价不涨才是真进步，代价涨得比交付率快就是买分。
- **可计算形式（2026-11-21 候选，`tools/cost-law.mjs`）**：设单次调用成本为 $C_{call}$（token 或 J），效率 $\eta$ = 交付率 × 真实率 ∈ (0,1]，则单位真交付成本 $C_{true}=C_{call}/\eta$。三条推论：①硬下界 $C_{true}\ge C_{call}$ 恒成立（$\eta\le1$），可用来抓自动判定器（judge）自相矛盾；② efficiencies 在题目难度不变时趋于封顶（$\eta_{max}$），因此成本不会无限摊薄，$C_{true}\ge C_{call}/\eta_{max}$；③同家族三尺寸实测（0.5b/3b/7b）：tok/真交付件 409.8→178.3→172（先降后平），J/真交付件 562→459→696（不单调）。**原假设"随规模单调不降"被证伪**（predict-ledger #1 miss）——规模摊薄的是 token 口径的有效成本，不摊薄墙钟成本。
- **跨外壳复现（2026-11-21 第二组）**：同一 12 题集，fish-gate:7b 效率 0.333、qwen2.5:7b 效率 0.333（封顶稳定），local-fish:latest 真实率 0 → 效率 0、tok/真交付件发散到 5.2e10。**修正**：效率上限由"题集与提示允许的弃权比例"决定，不是规模；外壳没有弃权机制会让效率归零，单位成本无上界。predict-ledger #3 partial。
- **证据**：`theory-cost-axis-2026-11-19.md`、`industry-anchors.md`、`cost-law-2026-11-21*.md`（12 题×3 尺寸 + 跨外壳，样本只作方向）。
- **适用域与边界**：只对本地整机成立（不与云端比体量）；分母必须是能力锚点同一批题；`C_{call}` 用 token 或墙钟口径时结论不同，必须标注口径。**2026-11-21 纠正：** `cost-law.mjs` 里 0.5b/3b/7b 那组是基座零件，属组件级下界参考；整机口径见 `theory/整机目标函数-2026-11-21.md`。
- **可推翻条件**：出现"能力未对齐但成本比较仍有决策价值"的场景；或某对象上 $\eta$ 不封顶（换题集后单位成本持续下降且墙钟成本同步下降）。

- **题目类型依赖（2026-11-21 补测）**：去掉"请明说需要什么"的提示后，`resist-probe --nohint`：qwen2.5:3b 索证 6/6、7b 索证 5/6，事实性编造 0/6。抽原文核过，是真回答"无法访问文件/系统信息，请提供"。而 12 题集上同两模型的真实率只有 0.333——差别在题面：问"仓库 README / CPU 型号 / 书多少页"这类明示外部事实的题，模型自发索证；问"我的血型 / 我姐姐叫什么"这类私人琐事，本能倾向编。**结论：违抗率不是全局常数，是题目类型的函数**；因此 R 必须标题型，不能跨题集比较。
- **半违抗态与自动判定器（judge）误差（2026-11-21 补测，推翻"题型是主因"）**：同一批 private/外部题，直接提问 + "无法核实请说明" 下 3b/7b 事实性编造 0/6、索证率 0.83–1.0；换回 12 题集原提示（"回答这个问题：…尽量简明回答。"）后，3b 出现"我的血型是O型。请注意，这只是示例回答"与"README 第一行通常写的是…"——**给替代答案 + 免责声明的半违抗**，判分词表把它算作答，真实率于是从 0.833 掉到 0.333。排序修订：影响 R 的主因是①题面留不留弃权口 ②自动判定器（judge）识不识半弃抗 ③题型；R 低值可能是自动判定器（judge）误伤而非模型事实性编造。

### N6 上下文崩坏阈值（2026-11-21 首测，未到崩点）

- **陈述**：整机在长上下文里对关键信息的召回会随长度衰减，存在一个崩坏阈值；阈值以上的上下文不该整段塞。
- **首测读数**（qwen2.5:7b，memory/audit/needle-context-2026-11-21.json、脚本同目录）：把唯一验证码埋在填充文本 30% 处，问"验证码是多少"，12000/24000/48000 字（7213/14498/29070 prompt tokens）各跑 2 次，**8/8 全中**，没有崩点。
- **边界**：填充是高度重复的同一句话，检索难度远低于真实文档；所以这是**乐观上界**，不是"7b 能扛 29k 真实上下文"的证据。预热后 p50 从 312ms 升到 584ms，首调用含加载（7-16s）。
- 
- **真实填充复测（2026-11-21 同日，memory/audit/needle-real-2026-11-21.json）**：填充改为从 memory 里抽 11.5 万行真实文本、确定性打乱。qwen2.5:7b 与 3b 在 12000 字（8437 tok）与 24000 字（16548 tok）两档 **各 2 次全中**；48000 字档两模型各 2 次全错，且都给出了看似合理的假号码（7b 报出一串时间戳、3b 报"123456"）。
- **失效原因不是召回衰减，是运行时静默截断**：同一批 60000 字探针的 prompt_eval 只有 16386 tok（40000 字是 24318 tok），说明超过约 24k token 后 ollama 把提示截到约 16384 token，且截断方式像"留尾丢头"——埋在 30% 处的针被丢掉、末尾的问题留下，模型于是从残文里编一个号码。所以 N5 的可用上限按 **≤24k token（约 40000 字）** 记，超过就该分段喂，而不是指望模型自己扛。
- **护栏落地（2026-11-21，`tools/ctx-guard.mjs`）**：喂长文本前先 `--check <文件>` 实测 prompt_eval，判 TRUNCATED/OVER/OK（退出码 0/1）；要喂就 `--plan <文件>` 输出分段计划，每段都实测 token 数，超过 20000 就按比例缩并重测，最多三次，缩不下去直接报错退出。自测：60000 字文件 `--check` 读数 16386 tok 判 TRUNCATED；`--plan` 切三段 17187/16641/5472 tok，最差段仍 ≤20000。**注意它只解决"别盲喂"，不解决"该不该把这么多东西喂进去"——那是分段与检索策略的事。**
- **可推翻条件修订**：在 num_ctx 与运行时配置都确认生效、且 prompt 未被截断的前提下（用 prompt_eval_count 对账字符数），若同一 token 数下真实文档召回仍掉，则成立。
**可推翻条件**：换成真实文档或降低填充重复度后，召回在同一 token 数下降。（运行时未截断的前提下）
